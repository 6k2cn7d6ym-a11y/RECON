# RECON 워크로그

날짜별 단일 파일로 관리한다. `worklog/YYYY-MM-DD.md` 형식.

## 규칙

1. **모든 팀은 자기 작업 완료 시** 오늘 워크로그 파일(`worklog/2026-07-09.md` 등)에 한 줄 append.
2. 파일 없으면 만들고, 있으면 자기 팀 섹션에 추가.
3. 형식:

```markdown
# YYYY-MM-DD 워크로그

## 개발팀
- (팀장·수석) 무엇을 했는지 한 줄. 산출물 위치까지.
- (대리·부리) 다음 작업 · 남은 것 명시.

## 마케팅팀
- (대리·베리) 카피 3안 초안 → _outbox/copy-drafts.md 결재 요청.
```

## 왜 이 폴더가 있나

- 팀 세션이 이어서 작업할 때 **어제까지 뭐가 됐는지 자기 스스로 알기 위해**.
- 대표 대신 팀끼리도 서로 뭐 했는지 볼 수 있게.
- 프로젝트 상세는 `CLAUDE.md`, 일단위 흐름은 이 폴더.
